Run one shell-free command inside ProcessKit's containment boundary.

Usage: processkit-cli [OPTIONS] <COMMAND>

Commands:
  run      Run a program inside a ProcessKit container and report its lifecycle
  inspect  Query a live run over local IPC
  cancel   Ask a live run to cancel (graceful where supported, then a hard kill), by `--run-id` or, in aggregate, `--all`
  kill     Hard-kill a live run's container immediately, by `--run-id` or, in aggregate, `--all`
  wait     Block until a run recorded in the per-user registry has finished
  events   Read back a run's JSONL lifecycle stream: render it, follow it, pass it through, or check it against the embedded event schema
  list     List every run recorded in the per-user registry, whatever its health (live/stale/unprobed)
  prune    Reap the registry's confirmed-stale entries — the leftover records of runners that died abruptly — while never touching a live run's entry
  probe    Report this binary's compatibility surface for a consumer's fail-closed compatibility preflight — no run, no child, no side effects
  help     Print this message or the help of the given subcommand(s)

Options:
      --error-format <format>
          How a runner-own failure is reported on stderr. `human` (the default) prints the historical `processkit-cli: <message>` prose; `json` prints exactly one bounded, versioned JSON object instead, so an adapter can branch on stable fields (`code`, `kind`, `retryable`) rather than parsing prose.
          
          Global on purpose — it is accepted before or after the subcommand, and every subcommand honors it. It never changes stdout, an exit code, or the default prose; clap's own parse-time usage errors stay human-readable in v1. See [`crate::error_envelope`] and `docs/exit-codes.md`.

          Possible values:
          - human: The historical free-text line, unchanged byte for byte
          - json:  One bounded, versioned JSON object per failed invocation (see [`crate::error_envelope`] and `fixtures/schema/cli/error.schema.json`)
          
          [default: human]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
